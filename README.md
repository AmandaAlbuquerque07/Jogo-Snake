# Jogo-Snake
O projeto consiste em uma releitura do jogo clássico da cobrinha(Snake), programado em linguagem **C** com o auxílio da biblioteca **raylib**.

## Projeto desenvolvido em grupo por:

- [Amanda Carolina Chaves Albuquerque](https://github.com/AmandaAlbuquerque07)
- [Giovana Menezes Lopes](https://github.com/GiovanaMenezesL)
- [Letícia Fernandes Melquíades](https://github.com/Leticiamelq)

## Sobre:
Este jogo foi proposto pelo professor Elverton Carvalho Fazzion como trabalho prático da diciplina de Laboratório De Programação II, no 2º semestre do curso de Ciência da Computação na Uniiversidade Federal de São João del-Rei.

O objetivo era recriar o Snake tradicional aplicando os conceitos vistos em aula, seguindo uma lista de especificações definidas pelo professor, como tamanho de tela, sons, barreiras etc.

Por isso, esta versão possui algumas regras e funcionalidades alteradas ou adicionadas para atender aos requisitos do trabalho.
